# OperationsFlow recording review

This candidate replaces the homepage product poster and OperationsFlow recording with a navy/indigo version of the existing executive screen. KPI values are blurred before capture, including the GIF, animated WebP and poster. Previous published recordings are retained.

The application renderer was reused in a separate local recording copy with synthetic data. The four held scenes show the overview and production, SCM and profitability KPI filters. This is not a new illustrative HTML dashboard and does not demonstrate all business menus or planning execution. Styling changes are limited to the recording copy; the operating application was not restyled or modified.

No internal application source, credentials, databases, input records, logs or local paths are included in this website change. The application has no verified publishing remote, so its source is excluded.
